🚀 Cómo Publicar tu Página Web Gratis

Guía rápida utilizando Termux y GitHub Pages

1️⃣ Crear el Repositorio en GitHub

Abre GitHub en tu navegador y crea un nuevo repositorio público para alojar tu proyecto.

  • Nombre del repositorio: paginaonline
  • Visibilidad: Public
  • Haz clic en el botón azul Create repository.

2️⃣ Configurar e Inicializar en Termux

Abre Termux en tu Android, crea tu carpeta de trabajo y genera el archivo principal index.html:

cd ~
mkdir misitio
cd misitio
nano index.html

Guarda el archivo en nano (CTRL + o, Enter, CTRL + x) e inicializa el repositorio:

git init
git branch -M main
git add index.html
git commit -m "Mi primera pagina online"

3️⃣ Conectar y Subir a GitHub

Vingula tu directorio local con GitHub y sube tu código:

git remote add origin https://github.com/solochegui/paginaonline.git
git push -u origin main

Nota: Introduce tu usuario y usa tu Personal Access Token (PAT) de GitHub como contraseña.

4️⃣ Activar GitHub Pages

Para publicar la web globalmente:

  1. Ve a tu repositorio en GitHub: https://github.com/solochegui/paginaonline
  2. Entra a Settings ➔ Pages.
  3. En Branch, selecciona main y haz clic en Save.
